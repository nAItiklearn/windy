    Questions

    Does Windy send my clipboard anywhere?

    No. History lives in a local database on your device. Windy makes no network requests while running.

    Will it record my passwords?

    Windy skips copies that password managers mark as sensitive, and you can ignore any app or any pattern you like in Settings.

    Is it the same as Maccy?

    No. Maccy is a macOS app. Windy follows the same simple behaviour but is a separate project that runs on Windows, macOS and Linux.

    Does it work on Linux Wayland?

    Clipboard history needs compositor support. It works on X11 and on Wayland desktops that provide the data-control protocol (such as KDE and wlroots-based ones). GNOME on Wayland has limits, documented in the project README.

    The installer says the publisher is unknown.

    Early builds are not code-signed, so Windows SmartScreen and macOS Gatekeeper warn you. The source and checksums are public so you can verify what you run.
