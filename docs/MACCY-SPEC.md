# Maccy behaviour spec (derived from source)

Source studied: `p0deje/Maccy` `master` (shallow clone, Oct 2026), MIT. Every statement below cites the
Swift file it comes from (paths relative to `Maccy/Maccy/`). Nothing here is copied code; it is a behavioural
description for an independent implementation. Items marked **[mac-only]** have no meaning off macOS and are
mapped in `PORTING-MAP.md`. Items marked **[off in Maccy]** exist in source but are disabled and are NOT ported.

## 1. Clipboard monitoring (`Clipboard.swift`)

- **Polling**, not events: a repeating timer every `clipboardCheckInterval` (default **0.5 s**) compares
  `NSPasteboard.changeCount` to the last seen value. Changing the interval restarts the timer (`AppDelegate`).
  Windy uses native change notifications where the OS has them and falls back to polling a sequence number.
- **Supported types** (`supportedTypes`): file URL, HTML, PNG, RTF, plain string, TIFF. Storage settings
  additionally allow JPEG and HEIC (`StorageType.images = png,tiff,jpeg,heic`).
- **Enabled types** (`enabledPasteboardTypes`, default = all): Settings > Storage has three toggles
  Files / Images / Text, each adding/removing the whole group (`StorageType.files|images|text`).
  `text = html, rtf, string`. If none of a copy's types is enabled, the copy is ignored.
- **Per-copy algorithm** when the change count moved:
  1. Record the new count. If the copy is not tagged as ours (`org.p0deje.Maccy` type), interrupt any paste stack.
  2. If `ignoreEvents` is on: if `ignoreOnlyNextEvent` is also on, reset both to false; then return (nothing stored).
  3. If the pasteboard's type set is disjoint from enabled types, **or** intersects the ignored set
     (`AutoGenerated`, `Concealed`, `Transient` + user `ignoredPasteboardTypes`), return.
  4. If the frontmost app's bundle id is ignored (see §2), return.
  5. Merge **all** pasteboard items into one record (BBEdit/Edge write two items). For each item:
     skip if it has a string that is empty/whitespace-only **and** no non-empty rich text (RTF/HTML);
     skip if any ignore-regexp matches the item's string; drop disabled types; drop non-persistable types.
  6. Microsoft Word link types (`com.microsoft.Link-Source` and `com.microsoft.ObjectLink` together) are
     dropped along with PDF.
  7. If nothing remains, return. Otherwise build the item (source app = frontmost bundle id), generate the title,
     call hooks, which end in `History.add`.
- **Non-persistable types**: Safari/Apple web archives (tens of MB), anything prefixed `dyn.` (dynamic UTIs),
  anything prefixed `com.microsoft.ole.source.`.
- **Our own writes**: every copy made by Maccy carries marker type `org.p0deje.Maccy` and
  `org.nspasteboard.source`. They are still captured (so the item bumps `lastCopiedAt`) but are
  recognised as "from Maccy", so the source application is not overwritten.
- **Clear system clipboard** (`clearSystemClipboard`, default off): after Clear / Clear all, the OS clipboard is emptied.
- Some apps (Chrome Remote Desktop, NetBeans) need Maccy to briefly activate and hide itself after a write to sync. **[mac-only]**

## 2. Ignore rules

| Rule | Setting | Default | Behaviour |
|---|---|---|---|
| Concealed / Transient / AutoGenerated types | built-in | always on | Copy ignored entirely |
| Custom ignored types | `ignoredPasteboardTypes` | `Pasteboard generator type`, `com.agilebits.onepassword`, `com.typeit4me.clipping`, `de.petermaurer.TransientPasteboardType`, `net.antelle.keeweb` | Copy ignored if any of its types is listed |
| Ignored apps | `ignoredApps` (bundle ids) | empty | Copy ignored if the frontmost app is listed |
| Invert | `ignoreAllAppsExceptListed` | false | Only listed apps are recorded |
| Ignore regexes | `ignoreRegexp` | empty | Any match on the item's plain string => item skipped. An invalid pattern makes the check return false (never blocks) |
| Ignore everything | `ignoreEvents` | false | Toggle in Advanced pane; also Option-click on the menu-bar icon |
| Ignore next copy only | `ignoreOnlyNextEvent` | false | Option+Shift-click on the icon: turns ignore on and arms "only next"; auto-reset after one copy |

Apps are ignored by the **frontmost app at poll time**, not by the true clipboard owner; this is an approximation in Maccy.
The status item shows a disabled appearance when `ignoreEvents` is on or no types are enabled.

## 3. History model and dedupe (`Models/HistoryItem.swift`, `Observables/History.swift`)

`HistoryItem`: `application` (source bundle id), `firstCopiedAt`, `lastCopiedAt`, `numberOfCopies` (default 1),
`pin` (nil or a single character), `title`, and a cascade-deleted list of `HistoryItemContent {type, value: Data}`.

- **Dedupe**: `History.findSimilarItem` looks for a stored item `E` (not the new item `N`) where `E.supersedes(N)`:
  every content of `N` whose type is not a noise type is present in `E` with identical type and bytes.
  Noise types: `x.nspasteboard.ModifiedType`, Maccy marker, `org.nspasteboard.source`, link-presentation metadata,
  WebKit and Chromium custom data / source URL / token, `com.apple.notes.richtext`.
  On a match `E` is deleted and `N` inherits `firstCopiedAt`, `numberOfCopies += E.numberOfCopies`, `pin`, `title`,
  and (unless `N` came from Maccy) `application`. `N.lastCopiedAt` is now, so the item moves to the top.
  If `E` was pinned, `N` takes its place in the pin list.
- **Modified-type shortcut**: if the copy carries `x.nspasteboard.ModifiedType` equal to a change count seen earlier this
  session, it is treated as an edit of that item (the old contents are not transferred).
- **Size limit** `historySize` default **200**, range 1...999. Only **unpinned** items count; the excess (lowest in the current sort)
  is deleted. Enforced on load and on insert (limit is `size - 1` before inserting an unpinned item, `size` for a pinned one).
- **Title** (`generateTitle`): images give an empty title, later replaced by OCR text (Vision) **[mac-only OCR]**;
  otherwise previewable text = file URLs (percent-decoded, newline joined) > plain text > RTF string > HTML string > previous title;
  shortened to 1,000 chars, scalars unsafe for layout stripped. If `showSpecialSymbols` (default true): a leading and a trailing
  run of spaces become `·`, `\n` becomes `⏎`, `\t` becomes `⇥`; otherwise the text is trimmed.
- **Sorting** (`Sorter`, `sortBy` default `lastCopiedAt`): `lastCopiedAt` | `firstCopiedAt` | `numberOfCopies`, all descending.
  Pinned items follow the user's `pinOrder`, then any pins not yet in the order list.
- **Pins** (`pinTo` default `top`; `bottom` supported): the pin is one key character, unique per item. Allowed set:
  `b c d e f g h i j k l m n o p r s t u x y [ ] ; ' . / - = \` minus the keys used by the delete / pin / preview shortcuts.
  (Reserved: a, q, v, w, z, `,`, `` ` ``.) A newly pinned item gets a random free character. Letters sort before symbols.
  Pin order is user-draggable (not while a search is active) and persisted (`pinOrder`). Pinned items show their pin character as
  the hint, are never removed by the size limit or by **Clear**, and survive dedupe.
- **Clear** (footer, ⌥⌘⌫): deletes all **unpinned** items. **Clear all** (⌥⇧⌘⌫): deletes everything including pins.
  Both close the popup and empty the system clipboard if `clearSystemClipboard`. Both ask for confirmation
  unless `suppressClearAlert` (default false) was ticked.
- **Clear on quit** (`clearOnQuit`, default false) runs Clear (unpinned only) at termination.
- **Delete item**: ⌥⌫ (configurable); selection moves to the nearest unselected visible item.

## 4. Search (`Search.swift`, `Observables/History.swift`)

- Modes (`searchMode`, default **exact**): `exact` (case-insensitive substring), `fuzzy` (Fuse, threshold **0.7**),
  `regexp` (ICU regex, unanchored), `mixed` = try exact; if zero results try regexp; if zero try fuzzy.
- Searches the **title** only (at most 1,000 chars). Fuzzy truncates its input to 5,000 chars.
- Fuzzy results are sorted by score ascending; other modes keep list order.
- Pinned and unpinned lists are searched separately; pins still honour `pinTo`.
- **Throttle** 0.2 s on query changes. After a search: empty query selects the first unpinned item; non-empty highlights the first result.
- Highlight (`highlightMatch`, default **bold**): `color` | `bold` | `italic` | `underline`, applied to match ranges
  on the first 500 chars of the title. `color` uses the system find-highlight background with black text.
- The search field is focused on open and typing goes to it. `showSearch` (default true) and `searchVisibility`
  (`always` default | `duringSearch`) control visibility.
- Enter with **no** selected item and a non-empty query copies the query text itself to the clipboard
  (`AppState.select` last branch) and clears the search.

## 5. Selection, paste and actions (`HistoryItemAction.swift`, `History.select`, `Clipboard.copy/paste`)

Settings `pasteByDefault` (false) and `removeFormattingByDefault` (false) decide what each modifier does on
Enter / click / number shortcut. Authoritative truth table is `HistoryItemAction.init`:

| pasteByDefault | removeFormattingByDefault | no modifier | ⌘ | ⌥ | ⌥⇧ | ⌘⇧ |
|---|---|---|---|---|---|---|
| false | false | copy | copy | **paste** | paste w/o formatting | none |
| false | true | copy w/o formatting | copy | paste w/o formatting | paste (with formatting) | none |
| true | false | **paste** | paste | copy | none | paste w/o formatting |
| true | true | paste w/o formatting | paste w/o formatting | copy | none | paste (with formatting) |

("none" = unknown action, ignored.) Preferences > General prints the live mapping.

- **Copy**: closes the popup, clears the pasteboard, writes every stored content (file URLs through `writeObjects` so multi-file works),
  adds the marker types, optionally notifies, re-reads the pasteboard.
- **Remove formatting**: keep only the plain-string content (plus file URLs if present). If the item has no plain string,
  behave as if formatting were not being removed.
- **Paste**: after copying, synthesise the app's Paste shortcut (⌘V, using the Paste menu item's real key if remapped, and a QWERTY keycode on
  layouts that switch to QWERTY under ⌘) via `CGEvent`; needs Accessibility permission **[mac-only mechanics]**.
- After any selection the search query is cleared.
- **Paste stack / multi-select** is in the code but `multiSelectionEnabled = false` **[off in Maccy]**. Not ported.

## 6. Popup (`FloatingPanel.swift`, `PopupPosition.swift`, `Observables/Popup.swift`)

- A non-activating floating panel (the previous app stays the active application, yet the panel is key for typing),
  level `statusBar`, no animation, rounded continuous corners. It closes when it loses key status unless an alert,
  item edit or drag is in progress. Appears on the active Space and over fullscreen apps.
- **Position** (`popupPosition`, default `cursor`): `cursor` (top-left at the mouse, constrained to the screen's visible frame),
  `statusItem` (below the menu-bar icon), `window` (centre of the frontmost app's window), `center` (screen centre),
  `lastPosition` (remembered as fractions of the screen, `windowPosition` default (0.5, 0.8), anchor = top-middle).
  `popupScreen` (0 = active screen, else an index) applies to `center` and `lastPosition`.
  The window is draggable by its background except in `statusItem` mode; position is saved on drag end.
- **Size**: `windowSize` default **450 x 800** (maximum); height shrinks to content with a minimum of 3 rows plus header and footer;
  user-resizable, size persisted. Height changes animate over 0.2 s.
- **Hotkey behaviour**: default global hotkey **⇧⌘C** toggles. Hold-to-cycle: while the modifiers stay held, each further press of the
  main key highlights the next item (wrapping); releasing all modifiers selects it. If modifiers are released before a second press it is
  a normal toggle.
- **Layout**: header (title "Maccy" if `showTitle`, default true, plus the search field), pinned section, history rows (title, optional
  app icon `showApplicationIcons` default false, optional hex-colour swatch `showHexColorSwatch` default true, image thumbnails up to
  `imageMaxHeight` default 40 (1...200) by 340 wide, right-aligned shortcut hint), footer under a divider.
- **Number hints**: the first 9 visible unpinned items get 1...9 hints; they are pressed with the modifier of the current default action
  (see §5). Pinned items show their pin character instead.
- **Footer** (`showFooter` default true): Clear (⌥⌘⌫), Clear all (⌥⇧⌘⌫), Preferences… (⌘,), About, Quit (⌘Q).
  With the footer hidden, Preferences stays reachable via ⌘, in the popup.
- **Preview slide-out**: opens beside the popup (left or right, depending on screen room) after `previewDelay` ms (default **1500**,
  200...100000) when `openPreviewAutomatically` (default true), or immediately through the toggle shortcut (default **⌃Space**).
  Shows full text (limited to 10,000 chars, paragraph size capped), the image at screen-limited size, or the file list, plus app name,
  copy count, dates and image size. Width `previewWidth` default 400, user-resizable.
- **Item editor** (`ItemEditorView`): text items can be edited in place; auto-close is suppressed while editing.

## 7. Keyboard (`KeyChord.swift`)

| Action | Keys |
|---|---|
| Open popup | ⇧⌘C (configurable) |
| Close | Esc |
| Select / act | Return, keypad Enter (modifiers per §5) |
| Next / previous | ↓ / ↑, ⌃N / ⌃P, ⌃J, ⌃K (when the first item is not highlighted) |
| Last / first | PageDown / PageUp, ⌘↓ ⌥↓ / ⌘↑ ⌥↑, ⌃⌥N / ⌃⌥P |
| Pin / unpin | ⌥P (configurable) |
| Delete item | ⌥⌫ (configurable) |
| Toggle preview | ⌃Space (configurable) |
| Clear / Clear all | ⌥⌘⌫ / ⌥⇧⌘⌫ |
| Preferences | ⌘, |
| Quit | ⌘Q |
| Search editing | ⌃U clear, ⌃H backspace, ⌃W delete word |
| Other ⌘/⌃/⌥ combinations | swallowed (`ignored`) |

The popup hotkey is global; pin, delete and preview shortcuts work only while the popup is open (Maccy disables them as global hotkeys).
Shift variants (⇧↓, ⇧↑) only extend a selection when multi-select is enabled, which it is not.

## 8. Menu-bar item and Settings

- Status item with selectable icon (`menuIcon`: maccy, clipboard, scissors, paperclip; default maccy), `showInStatusBar` default true,
  optional recent-copy text (`showRecentCopyInMenuBar` default false; the first 20 chars of the newest unpinned item, newlines removed).
  Click toggles the popup anchored at the icon; Option-click toggles ignore; Option+Shift-click ignores the next copy only.
- Settings window, five panes:
  - **General**: launch at login; check for updates automatically (+ Check now); popup / pin / delete / preview shortcuts;
    search mode; Paste automatically; Paste without formatting; link to system notification settings.
  - **Storage**: Save files / images / text; history size; sort by.
  - **Appearance**: popup at (+ screen choice); pin to top/bottom; image height; open preview automatically; preview delay;
    highlight matches; show special symbols; show menu icon (+ icon picker); show recent copy in menu bar; show search field
    (+ always / during search); show title before search field; show app icons; show hex colour swatch; show footer.
  - **Ignore**: tabs Applications (list, ignore-all-except), Pasteboard types, Regular expressions.
  - **Advanced**: turn off (ignoreEvents); clear history on quit; clear system clipboard after clearing history.
- Every default is in `Extensions/Defaults.Keys+Names.swift`; Windy's core exports its own table, checked by a test against this spec.

## 9. Storage, migrations, performance (`Storage.swift`, `AppDelegate.swift`)

- SwiftData/SQLite file `Application Support/Maccy/Storage.sqlite`; `HistoryItem` 1..* `HistoryItemContent` (cascade).
  Preferences live in `UserDefaults`. Windy uses one SQLite DB plus a JSON settings file.
- Versioned one-time migrations keyed by date in a `migrations` dictionary: 2.x key inversion (`hide*` to `show*`), add JPEG/HEIC to the image set,
  delete orphaned contents, sanitise titles (scalars that hang CoreText), remove unpersistable contents.
- Performance tricks: title capped at 1,000 chars, fuzzy input capped at 5,000, search throttled 200 ms, thumbnails and previews generated
  lazily on background tasks and cached per row, decoded-image caches released on delete, virtualised list.
- Test mode: the `enable-testing` argument swaps in an in-memory store and a separate preferences suite.

## 10. Accessibility and localisation

- VoiceOver labels per row (title or "image WxH", app name, "pinned"); status item label includes a "disabled" suffix when applicable.
- Strings come from per-pane `.strings` tables (`GeneralSettings`, `StorageSettings`, `AppearanceSettings`, `IgnoreSettings`, `AdvancedSettings`) and
  `Localizable`. Windy ships English first with the same key structure.

## 11. App Intents / Shortcuts **[mac-only]**

Clear, Delete, Get and Select actions via App Intents. Not ported (OS-specific automation surface).

## 12. What Maccy's tests cover (`MaccyTests/`)

- **Clipboard**: change listener and hooks; ignore whitespace-only and newline-only text; RTF and HTML not ignored; ignoreEvents and ignore-only-next;
  ignore application and ignore-all-except; ignore transient / custom / unknown types; copy; copy string; copy without formatting; items without data;
  merge multiple items; remove disabled types; remove dynamic types; do not store Safari web archive; frontmost app id.
- **HistoryItem**: title for string / RTF / HTML / file / image (+ OCR) / Universal Clipboard variants; empty item; letters-before-symbols pin order; several items with empty pin.
- **HistoryItemDecorator**: string, RTF, HTML, image, image above max height, file (incl. non-ASCII path), item without data, unpinned by default, deallocation, highlight.
- **Search**: simple, fuzzy, regexp. **Sorter**: by last copied, first copied, number of copies.
- Also: shortened-string, unsafe-title-scalars, collection-surrounding, colour-image tests and an XCUITest suite for the popup.
  Windy mirrors each as a Rust or Playwright test; mapping lives in `docs/TEST-MATRIX.md`.
